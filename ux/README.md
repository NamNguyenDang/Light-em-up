# Light-em-up — UX workspace

This workspace makes the design reasoning inspectable, not just the finished screen. Current delivery is a browser-local prototype. Online accounts/shared encouragement are deferred, and no representative user study or measured product outcome has been completed.

| Explore | What it demonstrates |
|---|---|
| [Case study](portfolio/case-study.md) | Problem, scope, role, decisions, validation and honest limitations. |
| [Evidence register](evidence/register.md) | Traceable stakeholder feedback, implementation and automated evaluation, separated from research assumptions. |
| [Assumptions and questions](research/assumptions.md) | What we believe versus what still needs discovery. |
| [Research plan](research/plan.md) | Proposed task-based evaluation and participant/data safeguards; not completed research. |
| [Journeys and state flows](flows/journeys.md) | Visitor/local-candle paths, error/recovery states and deferred online paths. |
| [Design decision log](design/decisions.md) | Alternatives, rationale, accessibility tradeoffs and source evidence. |
| [Evaluation and metrics](evaluation/plan-and-results.md) | Implemented checks, manual gaps and unmeasured outcomes. |
| [Session-note template](research/session-template.md) | A blank, explicit NOT RUN record for future genuine sessions. |
| [Portfolio checklist](portfolio/review-checklist.md) | What you can support with evidence and what you must verify before publishing. |

The [golden requirements](../docs/requirements/requirement.md) remain the behavior authority. [Standards](../docs/standards/README.md) are quality references; [lessons](../docs/lessons/README.md) retain mistakes. UX narratives must not silently change acceptance criteria or transform fixture results into user research.
