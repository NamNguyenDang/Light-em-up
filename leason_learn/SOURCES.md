# Primary sources

Checked 17 November 2026. External status can change; recheck when updating this audit. No paid ISO standard text was purchased or reproduced; ISO references use the official public catalogue/abstract only.

- [W3C WCAG 2.2 Recommendation](https://www.w3.org/TR/WCAG22/) — normative accessibility target and conformance requirements. The December 2024 edition incorporates errata. This project targets A/AA, not AAA.
- [W3C WCAG overview](https://www.w3.org/WAI/standards-guidelines/wcag/) — context on stable Recommendation versions; do not treat a draft as an implemented certification.
- [WAI disclosure navigation example](https://www.w3.org/WAI/ARIA/apg/patterns/disclosure/examples/disclosure-navigation/) — normal disclosure navigation does not require an ARIA menu role.
- [WAI dialog pattern](https://www.w3.org/WAI/ARIA/apg/patterns/dialog-modal/) — focus/keyboard guidance to supplement native dialog implementation and AT testing.
- [ISO 9241-210:2019](https://www.iso.org/standard/77520.html) — human-centred design process; catalogue says confirmed in 2025.
- [ISO 9241-11:2018](https://www.iso.org/standard/63500.html) — usability concepts/context.
- [ISO 9241-110:2020](https://www.iso.org/standard/75258.html) — interaction principles.
- [Microsoft Azure Architecture Center: Backends for Frontends](https://learn.microsoft.com/en-us/azure/architecture/patterns/backends-for-frontends) — dedicated frontend-tailored backend pattern and tradeoffs; it may add little value for one interface.
- [Google Web Vitals](https://web.dev/articles/vitals) — LCP/INP/CLS field evaluation guidance, separate from accessibility conformance.
- [Supabase RLS](https://supabase.com/docs/guides/database/postgres/row-level-security) — database authorization, auth.uid and role isolation.
- [Supabase JavaScript upsert/select](https://supabase.com/docs/reference/javascript/upsert) — SDK write/return behavior used by the repository adapter.

These references are different kinds of guidance. WCAG is the chosen web accessibility standard; ISO documents address broader human-system design/usability; APG and Web Vitals are implementation/performance guidance; BFF is an architecture pattern. There is no single universal SaaS screen-layout standard asserted by this audit.
